Como publicar novas fotos:
  1. Envie as imagens para a pasta gallery/ no seu site (pelo painel do hospedeiro).
  2. Use o formulário abaixo para montar a lista (nome do arquivo + legenda).
  3. Clique em Baixar gallery.json e substitua o arquivo gallery/gallery.json no servidor.
  4. Pronto — a página inicial atualiza automaticamente.
